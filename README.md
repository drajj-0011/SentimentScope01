# SentimentScope 🧭

**A tiny, fully offline sentiment-analysis API + web playground.**
TF-IDF + logistic regression, served with FastAPI. No API keys, no model downloads, no GPU — clone, install, run.

> **Author: Debraj**

---

## Why this exists

Most "AI demo" repos need a cloud key or a 500 MB model before they do anything. This one ships its own
540-sentence dataset and trains in about a second, so `pip install -r requirements.txt && uvicorn app.main:app`
gives you a working classifier — plus a browser UI and interactive OpenAPI docs.

> **A note on the numbers.** The bundled corpus is *synthetic and templated*, generated by
> `scripts/build_dataset.py` from disjoint sentiment lexicons plus deliberately overlapping contrastive
> sentences. A linear model therefore reaches a perfect held-out score. That is a statement about the
> dataset, **not** about real-world sentiment accuracy — swap in your own labelled CSV before quoting any
> metric publicly. The evaluation code is honest and reusable; only the corpus is a stand-in.

## Features

| | |
|---|---|
| **Offline by design** | Training data is bundled in `data/sentiment.csv` and regenerable from a fixed seed |
| **Explainable** | Every prediction returns the tokens that moved the decision (tf-idf value × model coefficient) |
| **Three classes** | `negative` / `neutral` / `positive` with calibrated probability scores |
| **Fast** | Sub-millisecond inference; typical latency printed per request |
| **Batch endpoint** | 50 sentences in one round trip |
| **Typed API** | Pydantic v2 schemas drive validation *and* auto-generated docs at `/docs` |
| **Tested** | `pytest` suite covering the model layer and every HTTP route |
| **Zero front-end build** | One HTML file, one CSS file, one JS file — no npm, no bundler |
| **CI included** | GitHub Actions runs the suite on Python 3.10 / 3.11 / 3.12 |

## Quick start

```bash
# 1. clone & enter
git clone https://github.com/<your-username>/debraj-sentimentscope.git
cd debraj-sentimentscope

# 2. virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. dependencies
pip install -r requirements.txt

# 4. (optional) pre-train and inspect metrics — the app trains on first boot anyway
python -m scripts.train

# 5. run
uvicorn app.main:app --reload
```

Open **http://127.0.0.1:8000** for the playground and **http://127.0.0.1:8000/docs** for Swagger UI.

## API reference

### `GET /api/health`
```json
{ "status": "ok", "model_loaded": true, "author": "Debraj" }
```

### `GET /api/model`
Model card: algorithm, label set, vocabulary size, accuracy, training timestamp.

### `POST /api/predict`
```bash
curl -X POST http://127.0.0.1:8000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "the battery life is amazing and setup took two minutes"}'
```

```json
{
  "label": "positive",
  "confidence": 0.9124,
  "scores": { "positive": 0.9124, "neutral": 0.0701, "negative": 0.0175 },
  "explanation": [
    { "token": "amazing", "weight": 0.4412 },
    { "token": "life", "weight": 0.1037 }
  ],
  "latency_ms": 0.42,
  "model_version": "1.0.0"
}
```

Send `"explain": false` to skip the token breakdown.

### `POST /api/predict/batch`
```bash
curl -X POST http://127.0.0.1:8000/api/predict/batch \
  -H "Content-Type: application/json" \
  -d '{"texts": ["i love it", "it arrived on tuesday", "worst purchase ever"]}'
```

Returns `{ "results": [...], "count": 3 }`.

## How it works

1. **Vectorise** — `TfidfVectorizer` with 1–2 word n-grams, unicode accent stripping, sublinear term frequency.
2. **Classify** — multinomial `LogisticRegression` (`C=8`, `class_weight="balanced"`) for the three labels.
3. **Explain** — for the winning class, `tfidf_value × coefficient` per token gives a signed contribution;
   the largest magnitudes are returned so a human can see *why*.
4. **Serve** — the fitted `Pipeline` is joblib-dumped to `artifacts/model.joblib` and loaded once at startup
   behind a lock, so concurrent requests reuse one in-memory model.

## Tests

```bash
pytest -q
```

The suite asserts that accuracy stays above 0.80 and macro-F-beta above 0.75 (a regression guard, not a
marketing figure), that probabilities sum to 1, that clear-cut sentences land in the right class, that
blank input is rejected, and that unknown vocabulary degrades gracefully instead of crashing.

## Extending it

- **Bigger data** — point `DATA_PATH` at your own CSV (`text,label`) and retrain; nothing else changes.
- **Stronger model** — swap the pipeline for `LinearSVC` or add `SGDClassifier(loss="modified_huber")`; the
  `SentimentModel` wrapper only needs `predict_proba` and `classes_`.
- **Persistence of feedback** — add a `POST /api/feedback` route writing corrections to SQLite, then retrain.
- **Deploy** — `uvicorn app.main:app --host 0.0.0.0 --port $PORT` works on Render, Railway, Fly.io or a
  free Hugging Face Space with no code changes.
